# Pollution Absorber: Improved

A fuel-burning air filter that absorbs pollution within an 80-tile radius.

**Factorio 2.1 · Version 1.0.5**

- Industrial cabinet with a native animated fan and working-state light.
- Cached sampling reduces the once-per-second script cost.
- Version 1.0.5 reduces repeated pollution-function lookups without changing absorption.

[Performance measurements](PERFORMANCE.md): a controlled 34-unit comparison reduced median update time from 0.333 to 0.211 ms. Absorption behavior is unchanged.

## Installation

Disable pollution-absorber before enabling this fork. Existing absorbers are retained.
